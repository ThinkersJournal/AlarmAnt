AlarmAnt: an emergency alert that cannot be ignored.

This release holds the A5 escalation state machine only (see DESIGN-A5.md). It is pure logic: no timers, HTTP, retries or provider code. The caller owns the clock and calls Alert::on when the timeout elapses or an acknowledgement arrives; sending goes through the AlertChannel trait.
